Nexus v1.5.0 (beta)

Please read this before using Nexus.

1. What Nexus is

Nexus is a student planner with an optional Chill Mode for music, video and manga. It is developed by Arch-Zylo, runs on your device, and is provided as-is for personal use.

2. Beta software

This is a beta release. Features can change, behave unexpectedly or be removed, and bugs can cause data loss. Do not rely on Nexus as the only copy of anything important.

3. Your data stays on this device

Classes, tasks, notes, people, wallet, events, passwords, settings and Chill Mode files are stored on this device only. There is no account and no cloud sync, and Nexus does not upload your data anywhere. Nexus works fully offline: it does not connect to the internet or contact any server. Uninstalling the app, clearing app data or switching phones can erase everything unless you export a backup.

4. Chill Mode files

Music, videos, manga pages, lyrics and other files you import are copied into Nexus's storage on this device and use space on it. You choose what to import and you are responsible for it: make sure you have the right to use it, that it is lawful, and that it is suitable for anyone who can use your device. Nexus does not supply, scan or moderate content. Song details (title, artist, cover, embedded lyrics) are read from the file on your device only. If you use Share, the file is handed to the app you choose.

5. Passwords are not encrypted

The Password Manager stores entries on this device in readable form, and they are included in backup files the same way. Do not store passwords here if others can access this phone. Keep the device locked.

6. Backups and wiping

Export in Settings creates a backup file. If you have Chill Mode files, it is a .nexusbackup file that includes them and can be large (up to about 4 GB). Backup files are not encrypted and contain everything, including passwords, so keep them somewhere safe. Importing a backup replaces your current data. Wipe All Data permanently deletes everything on this device, including Chill Mode files and the on-device backup copy, and cannot be undone. We cannot recover data you did not export.

7. Notifications

Reminders only work if you grant notification permission. Delivery is not guaranteed when the app is closed or the system restricts background activity. In a web browser, reminders only work while Nexus is open.

8. Accuracy

You are responsible for the information you enter (schedules, amounts, due dates). Nexus does not replace official school records or financial advice.

9. No warranty

Nexus is provided “as is”, without warranties of any kind. To the extent the law allows, the developer is not liable for lost data, missed reminders or any other damage from using it.

10. Changes

These terms are updated with new versions. When they change you will be asked to accept them again; continuing to use Nexus means you accept the current terms.

You can read these again anytime in Settings.
